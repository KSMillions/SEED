# 🌱 SEED

**AI-powered construction estimating and contract management platform**

> Never Underquote Again.

SEED is a modern SaaS web application that helps construction professionals in South Africa analyse tenders, build accurate estimates, and manage contract risks — all with unlimited AI analysis.

---

## Features

- **Tender Analysis** — AI-powered review of drawings, scopes, contracts and specifications
- **Estimate Builder** — Structured pricing schedules with reusable activity templates and a company resource library
- **AI Error Checking** — Detects gaps, errors, and missing requirements in your estimates
- **Risk & Contract Analysis** — Flags onerous contract clauses and quantifies project risks
- **Workbook Templates** — Reusable cost frameworks for common trade packages
- **Company Library** — Centralised resource rates (labour, plant, materials, subcontractors)

All features are **unlimited** — no credits, no tokens, no caps.

---

- **HTML5** — Semantic markup

## Getting Started

No build step required. Simply open `index.html` in your browser or serve with any static server:

```bash
npx serve .
```
